# Zeca e as Moedas

Demo de plataforma 2D em Godot 4.7. Zeca precisa chegar na bandeira pegando moedas e pisando nos bichinhos.

## Como jogar

Abrir o projeto no Godot 4.7 e rodar (F5).

| Ação | Teclas |
|---|---|
| Andar | A / D ou ← / → |
| Pular | Espaço, W ou ↑ |
| Reiniciar | R |

## Teste

```
godot --headless --path . --script res://tests/test_game.gd
```
